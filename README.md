# 小知AI——学术RAG项目

小知 AI 是一个 **学术智能问答系统**。  
它的目标是帮助研究人员和学生更高效地获取学术信息。用户在系统中提问后，系统会自动判断问题类型，并从 **论文知识库**、**网络搜索** 或 **大模型直答** 三种方式中选择最合适的路径来生成答案。  

为了保证结果可靠，小知 AI 还会进行多层次的质量检查，避免出现“答非所问”或不准确的情况。  
简单来说，它就像一个懂学术的智能助手，可以快速、准确地回答研究问题。
